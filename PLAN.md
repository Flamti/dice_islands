# PLAN.md — этапы разработки Dice Islands

15 этапов. Каждый заканчивается рабочим, тестируемым результатом и git-коммитом. Сеть — с этапа 1 (решение геймдизайнера). Перед началом каждого этапа — сверка со `SPEC.md`; расхождения уточняются у геймдизайнера.

Статусы: `[ ]` не начат, `[~]` в работе, `[x]` завершён и закоммичен.

---

## [x] Этап 1. Каркас сборки и сетевой каркас

Репозиторная структура из `ARCHITECTURE.md`; сабмодули godot-cpp (master + API-дампы из бинарника 4.7.1, официальной ветки 4.7 нет) и EnTT (v3.9.0); SConstruct; минимальное ядро с адаптером (версия + «эхо»-намерение); Godot-проект; ENet-лобби: создание партии (слоты 2–16, пароль), подключение гостя, назначение команд, добавление ИИ в слоты, кнопка «Готов»; намерения гоняются клиент → хост → подтверждение. Протокол намерений этапа 1 живёт в `game/scripts/net_session.gd` (транспорт — зона Godot); `core/src/net/` появится с этапа 2, когда в ядре будет стейт.

- **Файлы:** `core/SConstruct`, `core/extern/*`, `core/include/dicecore/core.hpp`, `core/src/core.cpp`, `core/src/adapter/*`, `core/tests/test_smoke.cpp`, `game/project.godot`, `game/addons/dicecore/dicecore.gdextension`, `game/scenes/lobby.tscn`, `game/scripts/{lobby,net_session,smoke_runner}.gd`, `scripts/{build,test,gd_check,net_smoke}.sh`
- **Тест:** `scripts/build.sh` собирает .so и регистрирует расширение (`--import`); `scripts/test.sh` — unit-тесты ядра; `scripts/net_smoke.sh` — интеграционный прогон: хост + отказ по неверному паролю + гость (видит слоты/команды/ИИ, эхо-намерение подтверждается ядром хоста).

## [x] Этап 2. Ядро ECS и Turn State Machine

Реестр EnTT; компоненты партии/игрока/ресурсов; стейт-машина фаз 0–9 (SPEC §4) с барьерами `PhaseReady` и таймерами фаз (настройка в лобби); автозавершение решений по таймеру; пустые авто-фазы. ИИ-заглушка: мгновенно шлёт `PhaseReady`.

- **Файлы:** `core/src/ecs/*`, `core/src/turn/*`, `core/src/net/intents.*`, `core/tests/test_turn.cpp`, `game/scripts/hud_phase.gd`, `game/ui/phase_bar.tscn`
- **Тест:** партия хост + 3 ИИ проходит 10 пустых ходов; в сети из двух людей фаза не завершается, пока оба не нажали «Готов» или не истёк таймер.

## [x] Этап 3. Генератор острова и строительная сетка

`math/`: Simplex Noise, RNG по сиду. `gen/`: воксельное поле → радиальная маска → Marching Cubes → UV по бесшовному атласу → GLB-экспорт. CLI-утилита генерации без Godot. В Godot: загрузка GLB, raycast-сетка (типы клеток по SPEC §11.3), отображение сетки, POI на свободных клетках.

- **Файлы:** `core/src/math/*`, `core/src/gen/*`, `core/tests/test_gen.cpp` (детерминизм: один сид → идентичный меш), `data/generator.json`, `game/scenes/island.tscn`, `game/scripts/island_view.gd`, `game/scripts/grid_overlay.gd`, `game/assets/atlas_placeholder.png`
- **Тест:** CLI по сиду выдаёт валидный GLB (повторяемо байт-в-байт); в игре у каждого участника лобби свой остров с наложенной сеткой.

## [x] Этап 4. Размещение зданий по сети

`data/buildings.json` (стартовый набор: замок, ферма, лесопилка, каменоломня, казарма); `BuildIntent`/`DemolishIntent` с валидацией на хосте (ресурсы, молотки, коллизии, габариты); заглушки-модели по габаритам; замок предразмещён; снос с возвратом 50%.

- **Файлы:** `data/buildings.json`, `core/src/systems/placement.*`, `core/src/ecs/components_building.*`, `core/tests/test_placement.cpp`, `game/scripts/build_mode.gd`, `game/scenes/building_stub.tscn`, `game/ui/build_panel.tscn`
- **Тест:** гость строит ферму — она появляется у всех; невалидная клетка/нехватка ресурсов отклоняются с причиной; снос освобождает клетки.

## [x] Этап 5. Кубики: доход, броски, рероллы, ресурсы

`data/dice.json` (грани по SPEC §6); фаза Дохода собирает пул кубиков от активных зданий; стейт-машина бросков (2 реролла, выбор подмножества); блокиратор крестов; конвертация граней в ресурсы; капы с сжиганием излишков (базовые, без складов); UI бросков.

- **Файлы:** `data/dice.json`, `core/src/systems/dice.*`, `core/src/systems/economy.*`, `core/tests/test_dice.cpp`, `game/ui/dice_tray.tscn`, `game/scripts/dice_tray.gd`, `game/ui/resource_bar.tscn`
- **Тест:** здания дают кубики; кресты невозможно выделить для переброса; ресурсы начисляются согласно `data/dice.json`; излишек сверх капа сгорает.

## [x] Этап 6. Еда и голод

Фаза Еды: апкип 1 еда/здание; нехватка → `Starving` в случайном порядке, детерминированном RNG хоста (SPEC §4, решение от 25.07.2026); `Starving` не даёт кубик; индикация голода.

- **Файлы:** `core/src/systems/upkeep.*`, `core/tests/test_upkeep.cpp`, `game/scripts/building_status.gd`
- **Тест:** при еде < числа зданий голодают случайные здания (повторяемо по сиду хоста) и не дают кубики; после подвоза еды статус снимается.

## [x] Этап 7. Шкала опасности и первая катастрофа

`data/disasters.json`; личные шкалы, пороги, сброс; катастрофа «Воры» (тяжесть I, Self); видимость чужих шкал; лента событий партии.

- **Файлы:** `data/disasters.json`, `core/src/systems/danger.*`, `core/tests/test_danger.cpp`, `game/ui/danger_meter.tscn`, `game/ui/event_feed.tscn`
- **Тест:** накопление крестов до порога триггерит кражу 25% случайного ресурса, шкала сбрасывается, событие видно всем.

## [ ] Этап 8. Полный набор мирных зданий и расширение острова

Достройка `data/buildings.json`: рынок, мастерская, школа, склад (+капы), мельница (смежность, SPEC §5), университет (без экрана исследований), порт (без рейдов), строительная платформа → клетки-леса в фазу 0 (SPEC §11.4); добыча POI молотками; детектор смежности.

- **Файлы:** `data/buildings.json`, `core/src/systems/adjacency.*`, `core/src/systems/expansion.*`, `core/src/systems/poi.*`, `core/tests/test_adjacency.cpp`, `game/scenes/scaffold_tile.tscn`
- **Тест:** мельница усиливает только смежные фермы; платформа на следующий ход добавляет ≤16 клеток-лесов только вне поверхности острова; склад поднимает капы.

## [ ] Этап 9. Боевое ядро: автосимуляция

Бойцы (статы из `data/combat.json`); детерминированная симуляция 20 тик/с в ядре: A* по сетке, стены как разрушаемые препятствия с оценкой «сломать vs обойти», башни, спавн гарнизона у казарм/замка, приоритеты целей, конец боя, статус `Destroyed`. Проверка без сети и портов — катастрофой «Нашествие пиратов». Стрим событий боя → визуализация (заглушки-капсулы).

- **Файлы:** `data/combat.json`, `core/src/systems/combat/*` (sim, pathfind, targeting), `core/tests/test_combat.cpp` (детерминизм: один сид → один исход), `game/scenes/battle_view.tscn`, `game/scripts/battle_view.gd`
- **Тест:** пиратский рейд ломает стену, если обход дороже, гибнет под башнями при плотной обороне; повтор с тем же сидом даёт идентичный лог боя.

## [ ] Этап 10. Рейды игроков

Фаза Набегов: отправка через активный порт (цель-здание/замок, численность ≤ вместимости, сторона высадки); гарнизон-оборона; общий бой всех рейдов хода на острове (союзники бьют цель вместе, враги сначала бьют юнитов конкурента — SPEC §9.3); рейд, разрушивший свою цель, отступает с наградой 30% (целиком нанёсшему последний удар), потерявший цель — без награды; запрет атак по своей команде; возврат выживших.

- **Файлы:** `core/src/systems/raid.*`, `core/src/net/intents.*` (RaidIntent), `core/tests/test_raid.cpp`, `game/ui/raid_panel.tscn`, `game/scripts/raid_panel.gd`
- **Тест:** в партии из двух людей рейд гостя разрушает ферму хоста и приносит 30% ресурсов; рейд на союзника невозможен; два враждебных рейда на один остров попадают в общий бой и атакуют юнитов друг друга, награду за цель получает нанёсший последний удар.

## [ ] Этап 11. Исследования

Экран исследований (открывается активным университетом); `data/research.json` — три ветки по SPEC §8; трата культуры уменьшает счёт победы; эффекты узлов экономики и войны; школа уже даёт культуру с этапа 8.

- **Файлы:** `data/research.json`, `core/src/systems/research.*`, `core/tests/test_research.cpp`, `game/ui/research_screen.tscn`, `game/scripts/research_screen.gd`
- **Тест:** до активации университета экран недоступен; «Фортификация» реально усиливает стены/башни в бою; баланс культуры и счёт победы уменьшаются на стоимость узла.

## [ ] Этап 12. Полный пул катастроф и магия

Оставшиеся катастрофы: молния, болезнь (+заражение смежных, лечение), саботаж, шторм (уязвимость лесов), метеорит, обрушение края (деструктор ландшафта: удаление клеток, ре-полигонизация чанка, гибель зданий); таргетинг Opponent; узлы магии: Ясновидение, Тёмная магия (выбор из 2 конкурентов, мини-решение 15 с), Обряд бури.

- **Файлы:** `data/disasters.json`, `core/src/systems/danger.*`, `core/src/gen/destruction.*`, `core/tests/test_disasters.cpp`, `game/ui/target_pick.tscn`
- **Тест:** обрушение удаляет связный кусок ≤10 крайних клеток вне замка и обновляет меш; болезнь распространяется только по смежным; с Тёмной магией приходит выбор из 2 целей.

## [ ] Этап 13. Победа, поражение, Чудо

Чудо (3 этапа стройки, удержание 1 ход); слушатели победы: военная/культурная (≥2× и ≥20)/чудо — по командам; выбывание игрока (руины, грабёж), режим наблюдателя; экран итогов; приоритет одновременных побед.

- **Файлы:** `core/src/systems/victory.*`, `core/tests/test_victory.cpp`, `data/buildings.json` (чудо), `game/ui/victory_screen.tscn`, `game/scripts/spectator.gd`
- **Тест:** сценарные тесты на все три победы и приоритет; разрушение последнего замка команды завершает партию; выбывший наблюдает.

## [ ] Этап 14. Сохранения и реконнект

Версионированный JSON-снапшот полного стейта (ECS + RNG + сиды) в фазу 0; автосейв-кольцо (5) + ручные слоты хоста; загрузка партии с переподключением гостей; реконнект по профилю с выдачей снапшота; передача слота ИИ при дисконнекте.

- **Файлы:** `core/src/save/*`, `core/tests/test_save.cpp` (снапшот → загрузка → идентичное продолжение по сиду), `game/ui/save_menu.tscn`, `game/scripts/session.gd`
- **Тест:** сейв на ходу N, загрузка, повтор хода с теми же намерениями даёт идентичный стейт; гость отваливается — доигрывает ИИ, гость возвращается и продолжает.

## [ ] Этап 15. Полировка и производительность

Обзорная камера карты (изолированная от логики — задел под VR); лента подсказок фаз; звуковые заглушки; перф-проход: инстансинг зданий, атласы, замеры на 16 островах (цель 60 FPS на RTX 3050 Mobile); прогон санитайзеров по ядру; финальная сверка со `SPEC.md`.

- **Файлы:** `game/scripts/camera_rig.gd`, `game/scenes/world_map.tscn`, `scripts/perf_check.sh`, точечные правки по результатам замеров
- **Тест:** полная партия 2 человека + 2 ИИ от лобби до победы без ошибок; 60 FPS в обзорной камере; ASan/LSan чисты.
